# A1 Curriculum Map — Fluency Static Curriculum

## Objetivo do A1

O A1 deve formar a base real do aluno. O aluno só deve avançar para A2 quando tiver visto e praticado o essencial de Grammar, Vocabulary, Reading, Listening, Speaking e Writing.

Total estimado: 119 aulas.
