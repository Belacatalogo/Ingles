## Aulas criadas neste bloco

Total: **5 aulas**

### Grammar

- `B1-GRAMMAR-009` — Second Conditional

Foco:
- estrutura: if + past simple / would + infinitivo;
- hipotético vs irreal (contraste com First Conditional);
- "If I were you" — forma fixa de conselho;
- erro "would" na cláusula if — explicação completa;
- 4 commonBrazilianMistakes (would na if-clause, were vs was, will na main clause);
- 2 controlledPractice, error correction, translation, 2 productionTasks.

- `B1-GRAMMAR-010` — Modal verbs for advice: should, ought to, had better

Foco:
- gradação: should (neutro) → ought to (formal/moral) → had better (urgente);
- "might want to" para sugestões diplomáticas;
- erro "should to" e "had better to" — os mais comuns no B1 brasileiro;
- tabela: Modal / Registro / Sentido / Exemplo;
- 4 commonBrazilianMistakes, 2 controlledPractice, error correction, translation, 2 productionTasks.

### Vocabulary

- `B1-VOCABULARY-007` — Problem and solution vocabulary

Foco:
- 12 palavras/expressões: face a problem, deal with, struggle with, cope with, overcome, resolve, tackle, address, run into problems, come up with a solution, figure out, work out;
- 7 chunks: I'm having trouble with..., The main issue is..., What would you suggest?, Have you tried...?, One option would be to..., It might help to...;
- 3 dangerousConfusions: problem/issue/trouble, overcome vs cope with, resolve vs solve;
- 1 miniDialogues (Ana + Ben, 5 linhas);
- 2 productionTasks.

### Speaking

- `B1-SPEAKING-004` — Describe a problem and ask for advice

Foco:
- situação: trabalho sobrecarregado, sem reconhecimento do manager;
- modelResponse ~120 palavras com struggle with, figure out, run into, pedido de conselho;
- 12 modelPhrases de problema e conselho;
- 2 substitutionDrills;
- 3 guidedSpeaking tasks (descrição do problema, pedido de conselho, dar conselho);
- 6 speakingChecklist;
- 1 recordingTask: 90-120s;
- 3 freeSpeaking prompts.

### Writing

- `B1-WRITING-004` — Write a piece of advice: email or message

Foco:
- modelText: email de conselho de Laura para Marcus (148 palavras);
- modelTextBreakdown: 10 notas (abertura empática, vocabulário, If I were you, should, ought to, had better, might want to, encorajamento);
- 4 commonWritingMistakes (should to, had better to, will no Second Conditional, encorajamento mecânico);
- 8 revisionChecklist items;
- draftTask, revisionTask, finalVersionTask.
