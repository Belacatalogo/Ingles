## Aulas criadas neste bloco

### Grammar

- `B1-GRAMMAR-005` — First Conditional

Foco:
- estrutura: if + present simple / will + infinitivo;
- situações reais e prováveis;
- variações: unless, as long as, provided that;
- erro mais comum: "if it will rain" — NUNCA "will" na cláusula if;
- controlledPractice, errorCorrection, translationPractice;
- produção: 4 frases pessoais com First Conditional.

- `B1-GRAMMAR-006` — Zero Conditional vs First Conditional

Foco:
- Zero: if + present simple / present simple — fatos universais;
- First: if + present simple / will — possibilidades futuras;
- "when" como equivalente de "if" no Zero;
- tabela comparativa dos dois tipos;
- produção: Zero sobre regras do trabalho + First sobre planos pessoais.

- `B1-GRAMMAR-007` — Expressing opinions: I think, I believe, In my view

Foco:
- gradação: I'm certain → I believe → In my view → I'm not sure;
- "I think so / I don't think so" como resposta curta;
- erros comuns: "I am thinking that..." / "My thought is..." / dupla negativa;
- produção: 3 opiniões com frases diferentes + respostas curtas em voz alta.

### Vocabulary

- `B1-VOCABULARY-006` — Opinion and discussion vocabulary

Foco:
- 16 expressões: That's a fair point, I see what you mean, Having said that, On the one hand, What's more, To be fair, I'm not convinced, In contrast, That said, It's worth pointing out;
- 7 chunks de debate;
- confusões: Having said that + but (redundante), Although vs However, Despite of (errado);
- mini-diálogo sobre trabalho remoto com 5 linhas;
- produção: diálogo escrito + fala de 90s argumentada.

### Speaking

- `B1-SPEAKING-003` — Express and defend an opinion

Foco:
- estrutura completa: opinião → argumento 1 → argumento 2 → concessão → conclusão;
- situação modelo com resposta B1 de 591 chars;
- 7 modelPhrases de debate;
- 2 substitution drills;
- 3 guided speaking tasks;
- 6 checklist items;
- recording task: 90-120 segundos sobre trabalho remoto;
- 3 free speaking prompts.
